# Power BI Mini Dashboard

This is a mini dashboard created as part of my data analyst portfolio.

## Features
- Total Revenue, Total Orders, Total Customers, Average Order Value
- Revenue by Product chart
- Revenue by Country chart
- Interactive filters between KPIs and charts

## Files
- `MiniDashboard.pbix` → interactive Power BI file
- `MiniDashboard.pdf` → PDF export for quick preview
